# Splitly — перенос дизайна Google Stitch

Источник: архив Stitch (31 экран `code.html` + `screen.png`, две спецификации `DESIGN.md`,
`design_tokens.json`, отдельная иллюстрация). Архив лежит в `Concept/` и в репозиторий не
попадает. Работа идёт в ветке `splitly/stitch`.

Правило переноса: вёрстка и вид — из Stitch; токены — из двух `DESIGN.md`; логика, API, база,
авторизация и расчёты не меняются. HTML из Stitch не вставляется: экраны собраны на React и
Tailwind из существующих компонентов и данных.

## Внешние картинки

В HTML Stitch 150 разных картинок с `lh3.googleusercontent.com` (портреты, фото товаров,
обложки). Локально их нет, права на них неизвестны, адреса временные. Они не скачивались и не
используются:

- портреты → нарисованные аватары (`components/ui/Avatar.tsx`), у вошедших через Telegram — их фото;
- фото товаров в чеке → не показываются (позиции чека — текст);
- иллюстрация на обложке → присланный файл 1200×896, сохранён как
  `public/illustrations/friends.webp` в исходном размере, показывается только меньше; прежний
  векторный рисунок остался рядом как запасной.

Иконки: вместо шрифта Material Symbols из макета — уже подключённый набор lucide (близкие по
виду, без загрузки шрифта с Google). Tailwind с CDN не подключается.

### Ограничения и что осталось

Это границы сделанного; каждую можно снять отдельным решением.

- **Автоотправка напоминаний не сделана.** Бот не может написать человеку, который его не
  открывал, а рассылка от имени бота требует согласия получателя и серверной очереди. Сейчас
  сообщение отправляет сам человек. Чтобы сделать автоотправку: хранить согласие на сообщения от
  бота, добавить серверный вызов с ограничением частоты.
- **Избранное и отметка «прочитано» хранятся на устройстве**, как и «обычная валюта». На другом
  телефоне они свои. Синхронизация потребует таблицы в базе и миграции на рабочей базе владельца.
- **В уведомлениях нет приглашений и новых участников.** API не отдаёт, когда человек вошёл в
  группу; нужно добавить это поле на сервере. Push-уведомлений в Telegram тоже нет.
- **Автокурсы — только для семи валют** таблицы ЕЦБ: TRY, USD, EUR, GBP, PLN, CHF, JPY. Для RUB,
  KZT, GEL, AED, UAH, KWD источник курса не даёт — остаётся ручной ввод, и экран так и говорит.
- **Изображения товаров — рисованные иконки, не фотографии.** Фото конкретных товаров нет и не
  выдумываются.
- **Скачивание в Telegram переделано, но на телефонах не проверено.** Для настоящего аккаунта файл
  собирает сервер и отдаёт по адресу, годному 5 минут; адрес получает загрузчик Telegram или
  внешний браузер. Подробности и порядок проверки — `docs/notes/release-stitch.md`.
- **PDF весит около 370 КБ** при любом объёме: шрифт Inter встраивается целиком. С урезанием до
  использованных букв на странице пропадала большая часть текста (найдено просмотром файла).
- **Отчёт — по одной группе.** Сводного отчёта по всем группам нет.

Проверки, скриншоты, инструкция для Telegram и план выкладки с откатом — `docs/notes/release-stitch.md`.

### Новое в стеке

- `pdf-lib` 1.17.1 и `@pdf-lib/fontkit` 1.1.1 (MIT) — загружаются только при нажатии «Скачать PDF».
- `public/fonts/Inter-*.ttf` — шрифт Inter, лицензия SIL OFL (`public/fonts/OFL.txt`).
- `/api/v1/downloads` — два адреса: выдать ссылку на файл (нужна сессия) и отдать файл по ссылке
  (подписана, 5 минут, только чтение). Файл собирается тем же кодом, что и в демо (`lib/export/make.ts`).
- `/api/rates` — открытый адрес без сессии: отдаёт один и тот же общедоступный курс всем, ничего
  из данных Splitly не читает, принимает только пары из семи валют. Наружу ходит сервер, не
  страница: правила CSP не менялись.

## Расхождения, решённые в одну сторону

- **Валюта**: в макете символ `₺`, в приложении код (`TRY`), потому что валют бывает несколько.
- **Отступ по краям**: светлая тема макета — 20 px, тёмная — 16 px; оставлены 16 px в обеих.
- **Нижняя панель** в макете разная на разных экранах; выбран вариант главного экрана.
- **Приглушённый текст** `#737C76` из макета не проходит по контрасту (4,0:1); оставлен `#5F6862`.
- **Названия позиций чека**: в макете переведены; в приложении — как напечатано, перевод по галочке.
- **Сумма на карточке**: в макете «Общий баланс группы»; в приложении — сколько группа потратила,
  а кто кому должен показано отдельно, по каждой валюте.
- **Шаги сканера**: в макете подпись «Шаг 1 из 3» стоит на трёх разных экранах; в приложении съёмка,
  проверка и раздача — шаги 1, 2 и 3.
- **Проценты точности и «Чек обнаружен • Читаемость 100%»** из макета не показываются: таких
  измерений нет. Есть пометки «Проверено» (строку правил человек) и «Прочитано неуверенно».
- **Балансы по валютам и «Общий итог» на экране долгов** не повторяются: они уже стоят в карточке
  группы над вкладками.
- **«Умный инсайт» в аналитике** не добавлен: это сочинённый текст, а не расчёт.
- **Участники в карточке группы**: в макете лента с прокруткой, здесь плитки переносятся на
  новую строку — прокручиваемая лента без фокуса не проходит проверку доступности.

## Проверка

`npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test`, `npm run build`,
`npx playwright test` (телефон и компьютер, обе темы в проверке доступности). Файлы отчётов проверять ещё и

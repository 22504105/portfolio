# Portfolio overview

Five web projects, each in its own folder of this repository with its own stack and deployment.
All are concept projects: the businesses and data are invented, the software is real and running.
Case studies in English and Russian are in the folders below.

| Project | What it is | Stack | Live demo | Status |
|---|---|---|---|---|
| [NOVA Residence](../nova-residence) | Premium real-estate landing page | Next.js, TypeScript, Tailwind CSS, Motion | [open](https://nova-residence-five.vercel.app) | Completed |
| [CUT&CO](../barbershop-demo) | Barbershop site with online booking, staff and admin workspaces | Next.js, TypeScript, Supabase, PostgreSQL | [open](https://barbershop-demo-sable.vercel.app) | Built and tested; live as a demo without database |
| [Flowly](../flowly) | Business intelligence dashboard with CSV/XLSX import | Next.js, TypeScript, Supabase, Recharts | [open](https://flowly-nine-ochre.vercel.app/demo) | Completed |
| [Splitly](../splitly) | Telegram Mini App for shared expenses with a receipt scanner | Next.js, TypeScript, PostgreSQL, Tesseract.js | [open](https://splitly-self.vercel.app/en/demo) | Completed; phone checklist pending |
| [Questling](../questling) | English-learning game in Telegram with a Teacher Studio | Next.js, TypeScript, Supabase, S3 storage | [open](https://questling-dusky.vercel.app/en/demo) | Deployed; phone checklist pending |

## Summaries

**NOVA Residence.** A premium real-estate landing page for a fictional Istanbul development:
editorial design, residences with floor plans, gallery and a viewing request form. Fast,
responsive and accessible. [EN](nova-residence/case-study.en.md) · [RU](nova-residence/case-study.ru.md)

**CUT&CO.** A full booking system for a barbershop: bilingual site, online booking with email
confirmation, client, barber and admin workspaces with analytics, PWA. Double booking is made
impossible in PostgreSQL. [EN](cut-and-co/case-study.en.md) · [RU](cut-and-co/case-study.ru.md)

**Flowly.** A BI dashboard for small shops: import orders from CSV or Excel and get revenue,
customers, trends and a printable report, or try the full demo without signing up.
[EN](flowly/case-study.en.md) · [RU](flowly/case-study.ru.md)

**Splitly.** A Telegram Mini App for splitting group expenses: any currency, a receipt scanner that
runs on the phone, balances and simplified transfers, reports in PDF, XLSX and CSV.
[EN](splitly/case-study.en.md) · [RU](splitly/case-study.ru.md)

**Questling.** An English-learning game in Telegram with a Teacher Studio: story campaigns, quests,
word journal, voice acting; teachers build quests visually and see errors by question.
[EN](questling/case-study.en.md) · [RU](questling/case-study.ru.md)

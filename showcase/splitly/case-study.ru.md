## Обзор

Мини-приложение Telegram для общих расходов компании: поездки, съёмная квартира, ужины. Оно
записывает, кто платил и кто участвовал, делит честно до копейки, показывает, кто кому должен, и
сводит долги к короткому списку переводов. Чек можно сфотографировать и разделить по строкам.
Русский и английский интерфейс; демо в браузере работает на тех же экранах с выдуманными данными.

## Задача

Компании ведут счёт в чатах и таблицах, где разные валюты, неравные доли и округления быстро дают
итоги, которым никто не верит. Делить длинный чек из ресторана вручную утомительно, а просить
друзей поставить ещё одно приложение значит потерять половину из них.

## Решение

Splitly открывается внутри Telegram одним нажатием, вход по аккаунту Telegram с проверкой на
сервере. Каждый расход хранится в своей валюте и для долгов не пересчитывается; число знаков после
запятой берётся из самой валюты. Одна функция проверяет каждый расход в форме, в демо и на
сервере, а сама база отклоняет расход, у которого не сходятся оплаты и доли. Фото чека
распознаётся прямо на устройстве и никуда не загружается: пользователь проверяет строки,
раздаёт их участникам, и на сервер уходят только подтверждённые строки.

## Что сделано

- Разбор требований, правила работы с деньгами и модель данных (`docs/architecture.md`).
- Проверка входа через Telegram, подписанные сессии, проверка участия в группе на каждом запросе.
- Схема PostgreSQL с триггерами целостности; расход заменяется новым, а не правится на месте.
- Форма расхода: поровну, суммами или процентами; несколько плательщиков; возвраты.
- Сканер чеков на устройстве: подготовка снимка, распознавание, разбор, проверка, раздача позиций.
- Балансы, погашения, курсы валют (вручную или по кнопке из таблицы ЕЦБ), аналитика, лента
  событий, общий экран долгов.
- Отчёты PDF, XLSX и CSV; копия всех данных в JSON; скачивание, которое работает внутри Telegram.
- Полный перенос на утверждённый дизайн экранов, светлая и тёмная темы, широкий макет.
- 269 юнит-тестов и тестов базы, сквозные тесты на телефоне и компьютере с проверкой доступности
  axe, живая проверка на рабочей базе.

## Ключевые функции

- Вход через Telegram без паролей; демо в браузере со сбросом
- Группы с приглашением по ссылке или QR-коду, роли, участники без аккаунта
- Гибкое деление, несколько плательщиков, возвраты, полная история
- Сканер чеков: фото, строки, участники, всё на устройстве
- Балансы по валютам, упрощённые переводы, отметки об оплате
- Курсы валют только для итогов, никогда для долгов
- Аналитика, события с отметкой непрочитанного, готовые напоминания
- Отчёты PDF, XLSX и CSV

## Технологии

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Zod, decimal.js, Tesseract.js,
pdf-lib, PostgreSQL (Supabase), Telegram Mini App API, Vitest, Playwright, GitHub Actions. Хостинг
Vercel.

## Технические задачи

- **Точность денег.** Целые минимальные единицы с числом знаков по валюте (у иены 0, у кувейтского
  динара 3), одно правило наибольшего остатка для любого деления и отложенный триггер в базе,
  который отклоняет расход, если оплачено, итог и доли не совпадают.
- **Ограничения Telegram.** В Telegram Web приложение работает во фрейме, где cookie ненадёжны,
  поэтому сессия идёт в заголовке, а язык в адресе. Страница внутри Telegram не может сохранить
  файл, который сама сделала, поэтому отчёты собирает сервер и отдаёт загрузчику Telegram по
  подписанной ссылке на пять минут.
- **Чтение чеков на телефоне.** Снимок готовится без потерь качества, читается дважды (как есть и
  с выровненным фоном бумаги), результаты сводятся по суммам; наклон исправляется по положению
  слов. Цены находятся надёжно; названия на реальных термочеках пока распознаются плохо, и экран
  проверки это честно показывает.
- **Приватность.** Фото не покидает устройство; на сервер уходят только подтверждённые строки и
  хеш снимка.

Мини-приложение Telegram для общих расходов: гибкое деление в любой валюте, сканер чеков прямо на

# Flowly — Security and QA review (Phase 5)

**Who did this.** This review was done by the project's own developer, as a
separate pass against the built application and the live database. It is a self-review, not an
independent audit, and should be read as one.

## Threat model

| Who                                | What they might try                                                                                         | What stops it                                                                                                                                                                                                                                                              |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A visitor with no account          | Read or change anyone's data through the database API, using the public key that is in every page           | `anon` has no privilege on any table and may execute no function. Checked on the live database: every request answers 401                                                                                                                                                  |
| A signed-in user                   | Read, change or delete another user's data                                                                  | Row level security on every table, by ownership of the workspace; the import function checks ownership itself. Tested on a real PostgreSQL for every table and function, and on the live project by asking the API for every row as a second account                       |
| A signed-in user                   | Fill the free database, or store inconsistent data, by skipping the import wizard and writing rows directly | Since the hardening migration, orders, lines and customers can only be written by `import_orders`, which enforces that an order adds up to its lines, 500 orders per request, 50,000 per workspace. Batches are capped at 500 per workspace and their JSON at a fixed size |
| Whoever supplies a file            | Run code through a spreadsheet: formulas, macros, HTML in cells, a zip bomb                                 | Files are parsed in the browser as data. Formulas are never evaluated, macros never run, cells are rendered as text. A workbook's unpacked size is read from its directory before unpacking. Only `.csv` and `.xlsx`, checked by content as well as by name                |
| Whoever opens an export            | Be attacked by a cell that a spreadsheet runs as a formula                                                  | Text cells beginning with `=`, `+`, `-`, `@`, tab or carriage return are written with a leading apostrophe                                                                                                                                                                 |
| An attacker with a link            | Send a signed-in user somewhere else after sign-in (open redirect)                                          | `safeNext` follows only paths inside the application                                                                                                                                                                                                                       |
| An attacker with a page            | Frame the site and trick clicks (clickjacking); load scripts from elsewhere                                 | `frame-ancestors 'none'`, `X-Frame-Options: DENY`, a content security policy limited to the site itself and Supabase                                                                                                                                                       |
| Someone probing accounts           | Learn whether an email address is registered                                                                | Sign-up, sign-in and reset answer the same way whether or not the address exists                                                                                                                                                                                           |
| Someone with a stolen database key | —                                                                                                           | There is no service-role key in the application or in its hosting. The only keys deployed are the two public ones                                                                                                                                                          |

## Findings and what was done

| #   | Finding                                                                                                                                                      | Severity                                       | State                                                                                              |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 1   | A signed-in user could insert orders, lines and customers into their own workspace directly through the API, bypassing the import checks and the order limit | High (integrity, and exhausting the free tier) | **Fixed.** Direct insert revoked; `import_orders` is the only writer and verifies ownership itself |
| 2   | No ceiling on the number of import batches or on the size of their JSON                                                                                      | Medium                                         | **Fixed.** 500 batches per workspace; size checks                                                  |
| 3   | A workspace could be created with a time zone the system does not know (by calling the API directly), breaking that workspace's pages                        | Low                                            | **Fixed.** The database validates the name                                                         |
| 4   | A signed-out page render queried the database as a visitor and logged a 500 before redirecting                                                               | Low                                            | **Fixed** in Phase 3                                                                               |
| 5   | Stand-alone text links and the drawer's close button were smaller than the 24 px WCAG 2.2 asks for                                                           | Low (accessibility)                            | **Fixed.** At least 32 px                                                                          |
| 6   | Trigger functions were executable by the API roles (harmless: they cannot be called outside a trigger)                                                       | Informational                                  | **Fixed.** Revoked                                                                                 |
| 7   | After a failed sign-in the email field was cleared                                                                                                           | Low (usability)                                | **Fixed** in Phase 3                                                                               |

## Privileges on the live database

| Role            | Tables                                                                                                                                                                                                           | Functions                                                                                                          |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `anon`          | none                                                                                                                                                                                                             | none                                                                                                               |
| `authenticated` | `workspaces`: select, insert, delete, update of name, currency, time zone. `import_batches`: select, insert, delete, update of counts, status, log. `orders`, `order_lines`, `customers`: select and delete only | `import_orders`, `finish_import`, `delete_import`, `delete_workspace_data`, `delete_my_account`, and three helpers |

Every table has row level security. Two functions run with their owner's
rights, and each is bound to the caller: `import_orders` (looks the batch up
by the caller's id) and `delete_my_account` (takes no argument).

## Residual risks, not fixed

| Risk                                                          | Why it stays                                                                                                                                                        | What would close it                                                       |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| The review is a self-review                                   | No independent reviewer was available                                                                                                                               | An independent review                                                     |
| The reset email was not followed end to end                   | Sign-up, changing a password and the reset form's answer were checked on the deployed site (12 checks). Receiving the email and opening its link needs a real inbox | Ask for one reset link by hand and follow it                              |
| No rate limiting of its own                                   | Vercel's free plan has no limiter; Supabase limits auth attempts itself                                                                                             | A limiter in front, on a paid plan                                        |
| Inline scripts are allowed by the content security policy     | Next.js starts pages with them; nonces would make every page render on demand                                                                                       | Nonces                                                                    |
| A workspace's orders are all loaded for every page view       | It is what keeps every figure consistent; bounded at 50,000 orders                                                                                                  | Aggregating in SQL, at the cost of a second implementation of the metrics |
| Free tiers                                                    | A free database is paused after a week without use and has no dependable backups                                                                                    | A paid plan                                                               |
| Real devices                                                  | Checked in desktop Chrome, Firefox, WebKit and emulated phones, not on physical phones or real Safari                                                               | A manual pass                                                             |
| The PDF was checked for format and page size, not read by eye | No PDF renderer in the build environment                                                                                                                            | Open one                                                                  |
